# BrightSteps — Kids Ministry

A responsive, installable web app for Windows and phones. It works offline after its first online load and stores records locally in the current browser/device.

## Open it

For a quick preview, open `index.html` in a modern browser. For install and offline support, serve this folder over HTTPS (or localhost) and open it in the browser. On Windows, use the browser menu’s **Install app** option. On a phone, use **Add to Home Screen** / **Install app**.

## Features

- Class rosters grouped by age, with quick search and age-group assignment.
- Class sessions with a date and assigned Bible lesson.
- Per-session attendance with present, late, or absent status and individual remarks.
- Weekly reports with child-level attendance, age-group filtering, session summaries, and an absent-child follow-up list.
- Read-only guardian attendance preview for one selected child.
- Illustrated Bible story library with passage references, child-friendly summaries, big ideas, and activity ideas. Every built-in story now has five illustrated scenes, with captions and scripture references; tap any scene to open a full-size view. Scenes are bundled for offline use.
- Save stories for offline access, add your own stories with up to five pictures and captions, and search online for missing stories.
- Session activity archive for crafts and artwork, with optional child name, notes, and small photo.
- Calendar showing sessions and assigned lessons.
- JSON backup export for moving records to another device.

## Data and guardian privacy

Names, attendance, remarks, lessons, custom stories, and work-sample photos stay in the current browser on the current device. They do not sync between devices. Export backups regularly. The guardian view is a local read-only preview only; it is not protected by accounts and should not be shared online with real child records. A deployed guardian portal needs private guardian sign-in and a secure data service.

The Creation scenes use four human-made illustrations by Sue Bentley, credited and included under CC BY-SA 3.0, plus an original vector illustration for the garden scene. The other built-in stories use original hand-coded vector scenes, not AI-generated images. Credits are in IMAGE-CREDITS.txt. Teacher-added pictures stay on the current device. Read the cited passage from your preferred Bible translation when teaching.
